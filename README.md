# Quiz / Exam Management System

A Python-based command-line Quiz and Exam Management System.

## Features

- Student name input
- Multiple-choice questions
- Randomized questions
- Automatic score calculation
- Correct answer validation
- JSON file storage
- Exception handling
- Object-Oriented Programming

## Technologies

- Python
- OOP
- Lists
- Dictionaries
- Random module
- JSON file handling
- Exception handling
